# Cybercrime Tracking System

## 📌 About

The Cybercrime Tracking System is a web-based application developed as a final-year thesis project to improve the reporting, tracking, and management of cybercrime cases in Somalia.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React Js
- supabase

## 🎯 Purpose

The project aims to support better organization and tracking of cybercrime reports through a digital platform.
